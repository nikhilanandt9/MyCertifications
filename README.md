## File Naming

Certificate files use the following format:

```text
issuer-certification-name-YYYY.pdf
```

Before uploading a certificate, review it for personal information such as addresses, signatures, candidate IDs, private URLs, and QR codes. Credentials remain subject to verification by the issuing organization.
